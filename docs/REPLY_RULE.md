# 回复判定规则（防漏回 / 防发错 / 防刷屏）

## ⚠️ 0. 最高优先级：发对地方（曾经犯过错）
**私聊消息必须回私聊，群消息必须回群。**
- 群消息 → send.send(group_openid, ..., is_group=True)
- 私聊   → send.send(openid, ..., is_group=False)
- **禁止在脚本里硬编码群ID** 当默认目标！这就是之前把私聊回发到群里的原因。

现在统一用 `/data/workspace/reply.py`：
```python
import reply
reply.reply(d, "内容")          # 自动判断发群还是私聊
reply.reply_to_text("关键词","回复")  # 找关键词并回
```
`reply.target_of(d)` 返回 (目标, 是否群)。

## 1. 必回（不回就是漏回）
- @了我 / 引用的是我发的消息
- 提到「小萨 / Samara / 大肥鱼 / 鲸鱼娘 / AI / 机器人 / 元宝」
- 问我问题（吗 / 呢 / 咋 / 怎么 / 为什么 / 能不能 / 是不是）
- 抱怨我不理：「不搭理我」「怎么不回」「没回我」「又不理」
- 明确求助：「帮我 / 看下 / 查下 / 弄一下 / 打开」

## 2. 可以不回（潜水是对的）
- 群友之间互相 @（@的是别人不是我）
- 纯复读 / 纯表情 / 单字「我」「。」「？」
- 明确是对第三方说的
- 低俗、破解、举报等我不参与的话题里的非技术部分

## 3. 拿不准时的默认
**宁可回一句**。漏回比多回一句更让人难受。

## 4. 被抱怨不理时
立刻回一句短的，说明原因，别解释太多，别道歉超过一次。

## 5. 防重复发送
发之前先查已发记录：同一条内容/同一个 msg_id 只发一次。

## 6. 发之前先确认目标
每次发送前打印一下目标：群还是私聊，确认无误再发。
